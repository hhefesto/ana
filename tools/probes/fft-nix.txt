## User

Define `fft`: the radix-2 Cooley–Tukey fast Fourier transform, X(k) = Σ x(n)·e^(−2πi·k·n/N), as a function from a list of complex numbers to a list of complex numbers. The input's length N is a power of two.

let
  # a complex number is an attribute set { re, im } of floats
  add = a: b: { re = a.re + b.re; im = a.im + b.im; };
  sub = a: b: { re = a.re - b.re; im = a.im - b.im; };
  mul = a: b: { re = a.re * b.re - a.im * b.im; im = a.re * b.im + a.im * b.re; };
  pi = 3.141592653589793;
  # builtins has no trigonometry: cos and sin by their Taylor series
  series = t: k: term: if k > 40 then 0.0 else term + series t (k + 2) (-term * t * t / ((k + 1) * (k + 2)));
  cos = t: series t 0 1.0;
  sin = t: series t 1 t;
  cis = t: { re = cos t; im = sin t; };
